# Bueno

Private, local-first LLM assistant. Runs on the owner's own hardware — no
cloud inference dependency. Windows desktop (RTX 5070) hosts the model via
Ollama; Mac is the primary dev/client machine.

See `docs/ROADMAP.md` for the phase plan, `docs/ARCHITECTURE.md` for the
system design, and `docs/PROJECT_RULES.md` for the rules governing work on
this repo.

## Status
Phase 0 — scaffolding only. Nothing runnable yet.
