# Bueno

Private, local-first LLM assistant. Runs on the owner's own hardware — no cloud inference dependency. Windows desktop (RTX 5070) hosts the model via Ollama; Mac is the primary dev/client machine. Connected via Tailscale for remote access.

See `docs/ROADMAP.md` for the phase plan, `docs/ARCHITECTURE.md` for the system design, and `docs/OPERATIONS_GUIDE.md` for the rules governing work on this repo.

## Status

P0 — scaffolding only. Nothing runnable yet. P1 (inference host bring-up) blocked on physical access to the Windows box.
