# Bueno

Private, locally-run LLM. No cloud inference dependency. Windows desktop (RTX 5070) hosts the model via Ollama; Mac portability. Connected via Tailscale for remote access.

See `docs/ROADMAP.md` for the phase plan, `docs/ARCHITECTURE.md` for the system design, and `docs/OPERATIONS_GUIDE.md` for the rules governing work on this repo.
